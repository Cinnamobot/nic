**ナレーション:**
「AIが、NICを通じて気象庁のリアルタイムデータを取得し、正確に答えています。出典も明記されます。」

**[画面: 次の質問]**

**あなた:**
「いま長岡あたり雨降ってる？」

**Claude（NIC経由）:**

## 撮影メモ

- **データの鮮度**: 実演時の数値（警報・雨・気温）は撮影当日の実データに合わせて読み替えること。台本の数値は例。
- **リアルタイム質問が本命**: 「今、警報出てない？」「いま雨降ってる？」など**既存知識で答えられない質問**を必ず入れる。静的情報（湯沢の紹介等）はAIの学習データで答えられるため、デモの価値が下がる。
- **エラーも見せどころ**: 夏季に「今の積雪は？」と聞くとエラーになる。その時AIが「積雪データは冬季のみ提供です。11月〜4月にまた聞いてください」と案内する姿も、正直さ・信頼性のデモになる。
- **文字化け対策**: Windowsコンソールで日本語が化ける場合、`PYTHONIOENCODING=utf-8` を設定するか、`--json` 出力を使う。
- **MCPツール呼び出しの可視化**: Claude Desktopではツール呼び出しがUIに表示されるので、その画面を収録すると「AIがデータを取得している」ことが伝わりやすい。
- **BGM**: 新潟らしさを出すなら、雪・川・祭りの映像をバックに。
- **字幕**: 全編日本語字幕推奨（審査員が音声なしで見る可能性）。
- **3分厳守**: パート3（セットアップ）を省略し「設定1箇所」の画面だけ見せれば、さらに短縮可能。
