## パート3: セットアップ（0:50〜1:30）

**[画面]: ターミナルでインストール**

```bash
$ git clone <リポジトリURL>
$ cd nic
$ uv sync
```

**ナレーション:**
「セットアップはとても簡単です。インストールはこの1コマンド。
コードを書く必要は一切ありません。」

**[画面]: claude_desktop_config.json を開いて1行追加**

```json
{
  "mcpServers": {
    "nic": {
      "command": "uv",
      "args": ["--directory", "/path/to/nic", "run", "ngt-mcp"]
    }
  }
}
```

**ナレーション:**
「あとは、AIアシスタントの設定ファイルに、この1ブロックを追加するだけ。
**設定1箇所**で、あなたのAIが新潟の専門家になります。」

## パート4: 実演（1:30〜2:30）— 「今」の質問

**[画面]: Claude Desktopを開く。プロンプトを入力**

**あなた:**
「ねえ、今新潟で大雨とか警報出てない？」

**[画面]: AIがNICのMCPツールを呼び出す様子（ツール呼び出しが可視化される）**

**Claude（NIC経由）:**
「いま新潟県では、発表中の警報・注意報はありません。
さっきまで中越・上越で出ていた雷注意報も、20時31分付けで解除されています。
新潟地方気象台の発表（本日20:31時点）です。安心してください！」

**ナレーション:**
「AIが、NICを通じて気象庁の**リアルタイムデータ**を取得し、正確に答えています。
出典も明記されるので、信頼できる回答です。」

**[画面: 次の質問]**

**あなた:**
「いま長岡あたり雨降ってる？」

**Claude（NIC経由）:**
「長岡ではいま雨は降っていません。気象庁アメダス長岡の観測（22:30時点）で、1時間降水量は0.0mmです。
今のところ傘は必要なさそうですね。」

**ナレーション:**
「『今』の質問に、『今』のデータで答える。これがNICの価値です。
AIが持っている学習データには、今日の雨も、今の警報も、現在の積雪も含まれていません。
NICがそれを、公式データ源からリアルタイムに補います。」

**[画面: CLIでも実演（冬季は積雪バージョン）]**

```bash
$ ngt weather --station 長岡
$ ngt warning --level 市町村
```

**ナレーション:**
「CLIからも同じデータにアクセスできます。これはAIエージェントの『道具』として設計されています。
エージェントが`ngt`を実行して、ユーザーに自然な回答を返す——それがNICの使い方です。」

## 撮影メモ

- **データの鮮度**: 実演時の数値（警報・雨・気温）は撮影当日の実データに合わせて読み替えること。台本の数値は例。
- **リアルタイム質問が本命**: 「今、警報出てない？」「いま雨降ってる？」など**既存知識で答えられない質問**を必ず入れる。静的情報（湯沢の紹介等）はAIの学習データで答えられるため、デモの価値が下がる。
- **エラーも見せどころ**: 夏季に「今の積雪は？」と聞くとエラーになる。その時AIが「積雪データは冬季のみ提供です。11月〜4月にまた聞いてください」と案内する姿も、正直さ・信頼性のデモになる。
- **文字化け対策**: Windowsコンソールで日本語が化ける場合、`PYTHONIOENCODING=utf-8` を設定するか、`--json` 出力を使う。
- **MCPツール呼び出しの可視化**: Claude Desktopではツール呼び出しがUIに表示されるので、その画面を収録すると「AIがデータを取得している」ことが伝わりやすい。
- **BGM**: 新潟らしさを出すなら、雪・川・祭りの映像をバックに。
- **字幕**: 全編日本語字幕推奨（審査員が音声なしで見る可能性）。
- **3分厳守**: パート3（セットアップ）を省略し「設定1箇所」の画面だけ見せれば、さらに短縮可能。
